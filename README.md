# Site web — thème personnalisé Paheko

Thème configurable avec diaporama d’articles, navigation et présentation commune des modules.

## Installation

Le dossier du thème est `modules/theme_personnalise/`. Utilisez ce dossier avec la procédure d’installation des modules personnalisés correspondant à votre instance Paheko. Ne déplacez pas `module.ini` hors de ce dossier.

Vérifiez la compatibilité avec la version de Paheko utilisée avant le déploiement.
